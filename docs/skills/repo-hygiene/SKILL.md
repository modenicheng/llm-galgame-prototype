# 仓库卫生自检（repo hygiene）

目标不是"代码能跑"，而是**下一张任务卡的实现者不会因为前一张卡变得更慢**。
分两档运行：

| 档位 | 时机 | 内容 |
|---|---|---|
| 快速档 | 每完成 3–4 张任务卡 / 单次大改动后 | A（机械检查）+ B 的 1–4 条 + 本次新增文件的过目 |
| 完整档 | 每个阶段/里程碑收尾门（GH） | A + B + C + D 全部，且必须派发 subagent 独立复核 |

## A. 机械检查（先跑，零判断）

```bash
node scripts/hygiene-check.mjs    # 行数阈值 + 临时标记扫描，超限即 fail
npm test                          # 或仓库等价命令；红 = 一切暂停
```

- 阈值（本仓库校准值，脚本内可改）：源码 `.ts` > 900 行 fail（≥600 warn）；
  测试 `.ts` > 1500 fail（≥1000 warn）；文档 `.md` > 900 fail（≥600 warn）。
- 超限的**既有豁免**登记在脚本的 `ALLOWLIST`（附原因与清偿任务号）；新文件
  一律不得进豁免清单。
- 源码里的 `TODO`/`FIXME`/`HACK` 数量不得比上一门增加（脚本对比输出，人工核对）。

## B. 结构检查（读代码，subagent 复核）

完整档必须把下面这段 prompt 原样派发给一个**只读** subagent（general-purpose
或 Explore），不要自己检查自己：

> 你是代码评审员，只读不改。仓库根：本仓库。范围：`<git diff --name-only <上一门>..HEAD>`
> 加上这些文件：`<本次新增/重点文件列表>`。逐文件检查以下七条，输出问题清单，
> 每条格式 `文件:行号 [严重度 P1|P2|P3] 一句话问题 + 一句话修复建议`。没有问题的条目
> 不要编造。不要修改任何文件。
> 1. 单函数体 > 80 有效行 → 拆分为可命名的小函数；
> 2. 分支/循环/try/回调嵌套 > 4 层 → 早返回、抽函数、或数据结构化；
> 3. 相似代码块出现 ≥ 3 处 → 抽公共函数/类型；仅 2 处且语境不同 → 容忍；
> 4. 冗余逻辑：对同一数据重复校验/重复派生；对 zod 已校验的输入再手写一遍校验；
> 5. 过度防御：对内部调用方校验"不可能发生"的状态并静默兜底（吞错 catch、
>    undefined 兜底掩盖 bug）——内部不变量用断言/类型表达，跨边界才校验；
> 6. 补丁叠加：为绕开旧调用点而新增带默认值的参数、同名函数第二实现、
>    注释里出现"兼容/暂时/legacy/旧路径"——应重构旧路径而非并排新路径；
> 7. 死代码：未被引用的导出、被替换系统残留、永不进入的分支。

收到清单后：P1/P2 **当场修复**（这是门的一部分，不是后续工作）；P3 记入
执行清单偏差记录。修复后重跑 A。

## C. 契约与单一真源（每门必查）

1. **单一真源**：每类数据只有一个权威存放处（快照=运行时状态、边负载=回放、
   runs=周目流水、canon=世界真理……）。发现第二存放处即 P1。
2. **冻结契约**：改冻结 schema 字段集 = 停下登记阻塞，不允许顺手改
   （版本号递增 + 偏差记录是唯一合法路径）。
3. **依赖方向**：core 不 import node:*/adapters/apps（跑仓库的 architecture
   test；新增目录必须纳入其扫描范围）。
4. **配置**：删除的系统能力对应的配置键一并删（config 无死键）；新增配置键
   必须有 zod 默认值且被读取。

## D. 文档卫生（每门必查）

1. 进度文档（status / 执行清单勾选）与实际行为一致——以测试为准，不以记忆为准；
2. 本阶段设计偏离已记入偏差记录；重大偏离已回写设计 spec；
3. 源码注释中的 `docs/…§N` 引用仍可解析（被引文件与章节还在）；
4. 新文档进文档地图；超过阈值的文档拆分或归档（历史文档移入归档并注明）。

## E. 修复纪律（怎么处理发现的问题）

- **发现即修**：卫生问题不排"后续批次"，门的含义就是此刻通过；
- **重构优先于叠加**：改不动旧代码时，先重构使改动容易，再落新逻辑
  （"先移动再修改"两步分别 commit）；
- **测试随缝拆分**：源文件沿某条缝拆了，对应测试文件沿同缝拆，禁止留一个
  巨型测试文件配多个小源文件；
- **一次只修一类**：混在功能 commit 里的卫生重构单独成 commit
  （`refactor(scope): …`），保持 blame 可读。
