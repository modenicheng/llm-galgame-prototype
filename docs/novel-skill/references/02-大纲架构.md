# 02-大纲架构

## 模块定位

本模块管：全书骨架设计、卷级结构、结构节点布局、三线管理、大纲三张表、结构理论工具箱、续写路线规划、大纲自检。

本模块不管：悬念与伏笔的工艺定义（归《04-情节与悬念》，此处只管它们在大纲层的排布）、爽点与商业节点的展开（归《11-商业连载》）、状态文件的日常维护（归《09-长篇状态管理》）。

适用阶段：构思后期与大纲期；写到中途失速或接手半成品时的路线重建。输入是《01-立项与定位》产出的立项卡；输出是一份可执行的卷级大纲与三张排布表，交由《09-长篇状态管理》落盘维护。

## 一、大纲的本质：期待感的管理计划

### 目标

把大纲写成「读者期待感的管理计划」，而不是剧情事件列表。

### 原则

读者翻页不是因为你安排了事件，而是因为他们带着某种期待。大纲的真正职责是在全书尺度上分配四种时刻：读者何时**获得**（回报、爽点、情感推进）、何时**失去**（代价、挫败、不可逆损失）、何时**等到**（悬念兑现）、何时发现**认知被颠覆**（反转与暗线揭示）。剧情列表只回答「发生什么」，管理计划回答「读者此刻心里装着什么」。

### 操作指引

你应当在搭建大纲时为每个章节组回答四个问题，缺一不可：

1. **获得**：这一段读者得到什么正向回报？离上一次回报隔了多少章？
2. **失去**：这一段主角付出什么代价？代价是否可见、是否累积？
3. **等到**：这一段兑现了哪条悬念？兑现时是否同时抛出更大的新问题？
4. **颠覆**：这一段是否改变了读者或主角对已知信息的理解？

**正例（四问齐备的章节组条目）**：「第41-55章：主角查清对手资金链，获得读者期待三个月的『幕后名单』（获得）；为此烧掉了唯一能洗白身份的假证，被旧识永久拉黑（失去）；兑现『谁在给对手递消息』这一卷初中悬念，同时揭示名单上有一个不该出现的名字（等到+颠覆）。」
**反例（只有事件没有期待的条目）**：「第41-55章：主角调查、遇到麻烦、解决麻烦，实力提升。」——读者心里什么都没装着，这段大纲等于没写。

**双轨铁律：升级线与代价线必须并行。** 只有升级线（主角不断变强、不断赢）而没有代价线的大纲，必死于30万字——读者对一个只涨不跌的曲线失去紧张感。你应当为每一卷设置至少一个不可逆的损失事件（盟友、身体机能、关系、道德底线、机会），并保证代价随重复而复利累积，而非每次归零重启。检验方法：把大纲里所有「主角付出什么」的条目单独抽出来，如果抄不满一页，这份大纲不合格。

**颗粒度纪律：大纲只写到事件级与功能级。** 每个章节组写清「阶段目标—主要障碍—代价—悬念操作」即可；写清「谁在什么压力下做出什么选择」即可。你不应当把大纲细化到每章的对话内容和场面调度——过细的大纲会在初稿期剥夺即兴空间，一旦前文偏离就整段作废，反而加速失控。判断标准：大纲条目能让你在忘掉细节三个月后仍看懂「这一段为什么存在」。

## 二、结构节点：百分比节点表

### 目标

用一张百分比节点表锚定全书（或单卷）的骨架位置，每个节点写清功能与检验标准。

### 原则

长篇失控的根源不是写得差，而是结构事件没有落在该在的位置——中点过了30章还没转折、低谷从未降临。百分比节点表给你一个可检验的坐标系，且同一张表可映射到整书或单卷两个层级。

### 操作指引

| 节点   | 位置      | 功能              | 检验标准                                     |
| ---- | ------- | --------------- | ---------------------------------------- |
| 日常世界 | 0-10%   | 建立主角的平衡态与缺口     | 读者读完前10%能说出主角想要什么、缺什么                    |
| 激励事件 | 10-15%  | 打破平衡，抛出核心冲突     | 必须发生在主角身上；必须有不可撤回的具体选择；必须把主角赶出舒适区        |
| 第一转折 | 25%     | 主角做出不可逆选择，进入新世界 | 选择由主角主动做出（而非被推着走）；退路被明确关闭                |
| 中点   | 50%     | 假胜利或假失败，虚实转换    | 改变「主角知道什么」或「局势的规则」；主角从被动应对转为主动出击         |
| 第二转折 | 70-75%  | 对手动用真正实力，局势反转   | 反推进力量等于或大于主角此前的推进力量                      |
| 低谷   | 75-80%  | 一切尽失，濒临放弃       | 失去的必须是主角最珍视之物，不是道具或数值；随后在约80%处获得新认知、重新出发 |
| 高潮终局 | 85-100% | 核心冲突总爆发与解决      | 主角必须用全书学到的东西解决问题；代价可见；尾声建立新秩序（92-100%）   |

**双层映射**：这张表既适用于整书（以总字数为分母），也适用于单卷（以本卷字数为分母）。百万字级作品你应当两层同时用——整书层保证大结构不塌，单卷层保证每一卷内部有完整的起伏。映射时允许 ±5% 的弹性区间，但中点与两个转折点不允许漂出区间。

**双层映射示例**：一部120万字四卷作品，整书层的中点落在第60万字附近，即第三卷卷首；单卷层的中点落在每卷第15万字附近。于是第三卷的卷首同时承担「整书中点」的职责——本卷开场即应发生认知颠覆而非重新铺垫日常。你应当在做双层映射时找出这类「重合点」并明确其归属层级，否则重合点的功能会被单卷的常规开篇稀释掉。

**节点之间的空档**是长篇最容易塌陷的地方：50%-75% 这一段没有任何结构节点，你必须在其中安排至少一个章节组级的假高潮或局部挫败来填充张力，否则这段会滑成事件流水账。

## 三、结构理论工具箱

### 目标

把经典剧作理论压缩成可查表，需要时按表对位，不做理论展开。

### 原则

理论的价值在于给出位置与功能，不在于术语本身。你应当把它们当作骨架校准工具，在大纲搭好后逐条对照，而不是先理论后故事。

### 3.1 救猫咪15节拍（Beat Sheet）

| 节拍    | 位置      | 功能                           |
| ----- | ------- | ---------------------------- |
| 开场画面  | 0-1%    | 定调定基调，与终场画面形成镜像              |
| 主题呈现  | 5%      | 用一句话暗示全书主题                   |
| 设定    | 1-10%   | 主角日常世界与缺口                    |
| 催化剂   | 12%     | 改变一切的事件（即激励事件）               |
| 争论    | 12-25%  | 主角抗拒新使命，展示抗拒的理由              |
| 第二幕开始 | 25%     | 进入新世界（即第一转折）                 |
| B故事   | 22-27%  | 感情线或核心支线开工，往往承载真正主题          |
| 乐趣与游戏 | 25-50%  | 兑现题材承诺的最有趣段落（网文即打脸与升级的集中兑现区） |
| 中点    | 50%     | 假胜利/假失败（外部）+ 亲密时刻（内部）        |
| 坏人逼近  | 50-75%  | 外部障碍与内部疑虑同步升级                |
| 一切尽失  | 75%     | 假失败，常伴随「死亡与婚礼」式的不可逆失去        |
| 黑鸟时刻  | 75-80%  | 最低点，主角几乎放弃                   |
| 第三幕开始 | 80%     | 顿悟，获得新方案                     |
| 结局    | 80-99%  | 问题逐层解决，主题闭环                  |
| 终场画面  | 99-100% | 与开场镜像对照，验证主角变化               |

对照要点：终场画面必须能回答「主角和开场时相比变了什么」；B故事的位置提醒你——感情线与核心支线应在第一幕末开工，而不是拖到第二卷才想起。

### 3.2 麦基核心概念

* **主控思想（Controlling Idea）**：一句话公式 = 价值观 + 原因，即「X能够/无法达成Y，因为Z」。你应当在动笔前写出这句话并让它约束所有结构取舍。例：「真实联盟能够战胜制度性压迫，因为压迫依赖的正是彼此的不信任。」

* **人物真相（Character Truth）**：人物真相 = 压力下做出的选择，而非其想法或背景。压力越大，人物越真实。大纲层应用：在每个结构节点处，你应当注明主角在此压力下做出的具体选择，而不是注明主角的情绪反应。

* **人物弧光（Character Arc）**：最佳弧光是主角在追求外在目标的过程中，被迫改变内在信念。大纲层应用：把外在里程碑与内在转变节点写成两条并行的刻度，二者在中点与终局处交汇。人物系统的展开参见《03-人物系统》。

* **激励事件三要件**：发生在主角身上（10-15%）；有一个具体、清晰、无法撤回的选择；把主角赶出平衡状态。三者缺一则第一幕失效。

* **对抗力量守恒（Opposition）**：每一次推进必须有等量或更大的反推进；对手实力必须等于或超过主角。大纲层应用：在大纲上给主角每次升级配一个对手的对应动作，配不上就是失衡。

* **场景转折与代价展示**：每个场景必须有有意义的转折（而非无聊重复），并让读者感受到每一步的代价。这是你裁掉无效章节组的标准。

### 3.3 英雄之旅12阶段

适用于以成长为主线的小说（冒险、奇幻、成长向都市）。12阶段：普通世界 → 冒险召唤 → 拒绝召唤 → 遇见导师 → 跨越门槛 → 试炼盟友敌人 → 接近洞穴 → 严峻考验（死亡体验/直面最大恐惧）→ 获得奖赏 → 归来之路 → 复活（最终考验，脱胎换骨）→ 带回灵药（将改变带回普通世界）。

长篇适配要点：「带回灵药」在百万字尺度上对应终局后主角对初始世界的重新审视——这一步是弧光闭环的关键，连载中常被砍掉，你应当保留至少一个尾声章节组完成它。反英雄变体（被动卷入、被迫成长）在现代写作中更真实，可与英雄之旅叠加使用：被动开局 + 被迫完成全部12阶段。

### 3.4 三种结构的适用场景对比

| 结构    | 适用场景                | 核心特征                                           | 主要风险            |
| ----- | ------------------- | ---------------------------------------------- | --------------- |
| 三幕式   | 出版向中短篇、影视化叙事、单卷内部结构 | 25%/50%/75% 三个转折位，比例刚性                         | 第二幕中部（50-75%）塌陷 |
| 起承转合  | 中文叙事传统、单卷或章节组、情感向题材 | 「转」落在中点之后，重铺垫与余韵                               | 「承」与「转」功能重复（合掌） |
| 网文循环式 | 数十万字以上连载、平台商业化创作    | 金手指1-3章亮相、前10章完成首个打脸兑现、30-50章一个小弧、循环突破、感情线不越主线 | 循环无升级，沦为复读机     |

裁决规则：单卷内部你应当默认用三幕式或起承转合；全书骨架在30万字以下可用三幕式直贯，超过30万字必须切换为网文循环式（以章节组为循环单元）。循环式的每个循环必须至少改变一项：对手层级、规则边界、主角认知、代价量级——四项都不变的循环是废章。

## 四、卷级结构

### 目标

把全书拆成卷、把卷拆成章节组，每一层都绑定明确的跃迁目标与障碍。

### 原则

卷不是字数的等分，是「认知或能力层级」的等分。读者愿意读百万字，是因为每一卷结束时主角看世界的方式和上一卷不同。

### 4.1 四卷模板（每卷30万字）

以120万字四卷为基准模板，每卷你必须填写以下五项：

| 项目    | 要求                                      |
| ----- | --------------------------------------- |
| 卷主题   | 一句话：本卷回答什么问题、主角完成什么内在转变                 |
| 层级跃迁  | 能力或认知从X到Y（网文语境即金手指等级，如E级→D级）；必须有对应的代价抬升 |
| 主线里程碑 | 2-4个，落在本卷的节点位置上（激励事件、中点、低谷、卷末高潮）        |
| 卷末大悬念 | 本卷中悬念兑现 + 下一卷新中悬念抛出，同章完成交接              |
| 代价事件  | 至少一个不可逆损失                               |

四卷的层级跃迁必须构成递进序列（E→D→C→B→A），且每一卷的对手层级同步抬升——主角升级而对手不升级，等于没升级。

**四卷模板示例**（复仇主线，仅示意层级与代价的写法）：第一卷：层级 E→D，卷主题「从被害者变成猎人」，代价「为拿到入门资格当众否认自己的出身」；第二卷：D→C，主题「发现仇人只是棋子」，代价「亲手断送唯一的旧友关系」；第三卷：C→B，主题「成为自己曾憎恨的那种人」，代价「身体机能不可逆损伤」；第四卷：B→A，主题「复仇完成后如何自处」，代价「失去复仇所依赖的全部身份」。注意每一卷的代价都不在同一维度上重复——重复维度的代价不构成递进。

### 4.2 章节组拆分

每卷切成3-5个章节组，每组8-30章。每个章节组你必须写清六个字段：

1. **章节范围**：ch X–Y
2. **阶段目标**：本组结束时主角得到什么、失去什么（各至少一项）
3. **主要障碍**：谁或什么在阻止，其层级与上一组障碍的关系（必须更高或不同维度）
4. **代价事件**：本组付出的可见代价
5. **悬念操作**：本组埋下什么（伏笔/悬念）、兑现什么
6. **组末钩子**：弧钩子，即本组最后一章抛出的、牵引下一组的问题

章节组是大纲的最小规划单元。组内各章你只标注功能标签（推进/转折/喘息/兑现），不展开内容——这是保持弹性的边界。

### 4.3 更短篇目的等比缩放

比例不变，字数等比压缩。30万字：三卷，每卷10万字，章节组缩至3-8章；60万字：四卷，每卷15万字，章节组5-15章；15万字以下：不用卷层，直接用三幕式+章节组。缩放时节点百分比位置一律不动，只压缩节点之间的空档。连载中若整体篇幅预期变化，你应当按此表重新分配而不是临时增删章节组。

## 五、三线管理

### 目标

在大纲层分配主线、支线、暗线的开工与闭合位置，并维持三线的纪律。

### 原则

三线的价值在于节奏差：主线给读者方向感，支线给变化与呼吸，暗线给终局的震撼。三线同速推进、同时高潮，是长篇最常见的结构性灾难。

### 5.1 三线定义与排布

* **主线**：贯穿全书，一句话能说清。纪律：每卷必须迈上一个清晰的大台阶，且台阶之间不可跳级。

* **支线**：卷内开合。纪律：每条支线必须服务主线或人物弧，两者都不服务的支线直接砍掉；同一时段活跃支线不超过2-3条；感情线属于支线，可以推进但不可以越位成为主线的支配力量。

* **暗线**：跨卷积累、终局重构认知。纪律：全书暗线1-2条封顶；每卷至少一次低强度露面（藏于日常，不点破）；暗线素材必须提前以「看似无害」的形态散布在已读内容中。

### 5.2 开工与闭合纪律

**开工**：

* 主线在激励事件处开工，且第一卷前三章内主线问题必须清晰亮相。

* 支线在本卷前1/3内开工；若一条支线需要跨卷延续，你应当将其升格为暗线并按暗线纪律管理，而不是让它以支线身份悬置。

* 暗线在第一卷即埋下第一笔，按重伏笔级别处理（出现3次以上、藏于日常）。

**闭合**：

* 支线在本卷结束前必须闭合，且闭合时必须对主线产生实质影响——提供信息、改变关系、交付资源、制造转折皆可；闭合后对主线毫无影响的支线是装饰，应在大纲期删除。

* 暗线的终局揭示必须重构读者对已读内容的认知：读者回看时发现所有线索都指向另一个方向。只是「补充一段新信息」不算重构，只是说明。

* 三线不得在同一章到达高潮。你应当错峰：主线高潮在前、支线收束紧随、暗线揭示压轴（或反之），彼此间隔至少数章。

**错峰示例**：卷末三章的分配——倒数第三章：主线对决分出胜负（本卷叙事强度最高点）；倒数第二章：支线人物在此战后果中完成各自的收束，其中一人带走一条新伏笔（支线闭合）；末章：日常场景里出现一个此前出现过三次、从未被注意的细节，指向全书暗线（暗线露面，强度回落）。三个高潮若挤在同一章，读者来不及消化任何一个。

## 六、大纲三张表

### 目标

用反转表、伏笔回报表、悬念表三张表，把「何时埋、何时收」从记忆问题变成排布问题。

### 原则

三张表是大纲的执行面：骨架告诉你结构在哪，三张表告诉你读者的期待在哪一条上被牵引、在哪一章被兑现。表结构的具体字段定义归《04-情节与悬念》，本模块只负责章节分配策略。

### 6.1 反转表

字段：反转章节 × 反转内容 × 铺垫章节。

排布规则：

* **无铺垫的反转是欺骗。** 每个反转至少标注2个铺垫章节，且铺垫应分布在不同章节组，间隔越远冲击越大。

* 铺垫内容在抛出时必须以「看似无害」或「另有所指」的形态出现，不得自带强调。

* 反转密度上限：每卷2-4次有效反转；连续两章出现反转会让读者脱敏。

* 大反转（重构认知级）全书2-3次，位置优先放在中点与终局，并与暗线揭示共用素材。

### 6.2 伏笔回报表

字段：伏笔 × 抛出章节 × 回报章节 × 回报方式。

排布规则（按伏笔三层次分配）：

* 浅伏笔（出现1次）：回报距离不超过15章，本章节组或下一组内兑现。

* 中伏笔（出现2-3次）：跨章节组，第二次出现应换一个语境，回报落在卷内。

* 重伏笔（3次以上，藏于日常）：跨卷，回报落在卷末或终局；每次出现的形态都不得重复。

* **沉默期上限**：任何伏笔沉默超过50章，必须在沉默期内安排一次低强度提醒（一笔带过、一个呼应意象、一句闲谈提及），否则读者会判定作者忘了。

* 回报方式一栏必须写明「以什么形态回报」——同一形态（如同一句台词回收）全书不超过2次。

### 6.3 悬念表

字段：悬念 × 抛出章节 × 计划揭示章节 × 级别 × 状态（开启/推进/已回收/搁置/断裂，口径见《04-情节与悬念》四节）。

排布规则（按悬念三级分配）：

* 小悬念（1-3章内回答）：任何时刻每章至少有1个处于活跃态；在章末抛出、3章内兑现是默认节奏。

* 中悬念（卷内揭示）：每卷同时活跃2-4个；卷首抛出或承接，卷末前兑现。

* 大悬念（全书揭示）：全书不超过3个；终局揭示时必须同步抛出全书钩子的最终答案与新秩序的余韵。

* **悬念链规则**：任何一级悬念兑现的同一章或紧邻章，必须抛出一个同级或更高级的新问题，兑现与抛出成对出现、链条不得断开——这是排布层的硬约束，悬念本身的工艺规则参见《04-情节与悬念》。

* 悬念库存健康度：当前活跃悬念总量维持在5-9条（口径见《04-情节与悬念》四节）。只有1条读者会疲劳，超过9条读者会放弃追踪。

### 6.4 章节分配策略（何时埋、何时收）

把三张表的行落到章节组的固定位置上：

* **卷首3章**：兑现上一卷遗留的中悬念尾钩 + 抛出本卷新中悬念。

* **章节组中段**：埋浅伏笔、制造小悬念的密集区。

* **章节组末章**：集中兑现本组小悬念 + 抛出弧钩子。

* **中点**：安排一次重伏笔的中途提醒，或一次改变认知的中级反转。

* **低谷前后**：伏笔回报表在此集中清偿——低谷时主角可动用的资源应恰好来自早前埋下的伏笔，这是「用学到的东西解决问题」的结构落法。

* **卷末**：中悬念兑现 + 大悬念加压（不揭示，只收窄或倒转方向）。

* **终局前一个章节组**：三张表所有未清偿行进入「就位」状态，逐项检查是否有遗漏的回报。

三张表建好后交由《09-长篇状态管理》随写作进度更新维护；商业节点（黄金三章、签约节点、付费钩子）在骨架上的排布参见《11-商业连载》。

## 七、续写路线规划

### 目标

在接手半成品或写到中途失速时，重建大纲并给出可执行的近期推进方案。

### 原则

失速几乎从来不是文笔问题，而是结构问题：节点缺失、悬念库存枯竭、代价线断裂、支线失控。重建的顺序是先诊断后开药，且必须以「已写内容不可推翻」为前提。

### 操作指引

按四步执行，顺序不可颠倒：

**第一步：体检。** 通读全部已有稿（不可跳读），判断失速原因，按四类归因：结构节点缺失（最常见：中点无转折、低谷未降临）、悬念库存枯竭（活跃悬念≤1条）、代价线断裂（主角只赢不输）、支线失控（活跃支线>3条或跨卷未闭合）。你应当同时列出不可动项清单：哪些设定、基调、人物关系、已兑现承诺不能被推翻。

**第二步：提取已有结构。** 从已有稿反推实际结构：已用掉哪些节点及其实际位置、当前活跃的悬念清单、未回报的伏笔清单、三线各自的当前状态、主角此刻的能力/认知层级与情绪基线。这一步的产出是「实际骨架图」，它可能与原作者宣称的大纲不一致——以实际稿为准。

**第三步：补齐节点。** 把缺失的结构事件放到未来3-5章可及的位置上，允许「迟到」但不允许「跳过」：中点已过而无转折，则在下一章节组补一次迟到的认知颠覆；低谷从未降临，则在补齐时让代价一次性清偿（积累的代价在此集中爆发，冲击反而更大）。同时修正三线：砍掉失控支线或将其升格为暗线、为枯竭的悬念库存补抛2-3条新悬念。

**第四步：未来3-5章推进要点。** 每章给出五项：本章功能（推进主线/情绪转折/支线收束）、核心事件、情绪落点、与前文的衔接点、不可动项。每章介绍控制在200-300字，不展开对话与场面。写到第3-5章后你应当回到第一步重做一次微体检，滚动前进。

## 八、大纲自检

交稿前逐项过检，任何一项不过即返工：

1. **节点齐全**：六个结构节点（激励事件/第一转折/中点/第二转折/低谷/高潮终局）在整书层与单卷层都有落位，且位置在 ±5% 弹性区间内。
2. **三线各有排布**：每卷主线迈一个大台阶；活跃支线≤3且卷内闭合；暗线本卷至少一次低强度露面。
3. **每卷有代价事件**：且代价随卷数复利累积，不是每次归零。
4. **暗线有积累记录**：暗线的每次露面都标注了章节号与形态，终局揭示能重构认知。
5. **反转表无裸反转**：每个反转都有≥2个铺垫章节，铺垫形态看似无害。
6. **伏笔沉默期≤50章**：所有超期伏笔已安排低强度提醒。
7. **悬念库存健康**：活跃悬念5-9条，悬念链无断点，兑现与抛出成对出现。
8. **层级递进成立**：四卷（或N卷）的层级跃迁与对手层级同步递增，无跳级、无停滞。
9. **双轨并行**：抽出全部「获得」条目与全部「失去」条目，两列长度大体相当。
10. **颗粒度合规**：大纲最细到章节组字段与章节功能标签，未细化到对话与场面。

卷写完后的实际成稿审计，使用《10-审计与修订》的卷级十维清单。

## 九、常见误区

* **中点无转折**：中点只是事件堆积或一次普通胜利。中点必须改变「主角知道什么」或「局势的规则」，否则第二幕前半全部作废。

* **支线开花不闭合**：支线开得热闹，超过一卷仍未闭合即已失控；闭合时对主线毫无影响的支线应在大纲期删除。

* **大纲细到每章对话**：剥夺初稿的即兴空间，前文一偏就整段作废。大纲止于事件级与功能级。

* **只有升级线**：主角只涨不跌，30万字后读者对无风险曲线失去紧张感。每一卷配一次不可逆损失。

* **第二幕中部塌陷**：50-75%无任何结构事件，滑成流水账。在此区间强制安排章节组级假高潮或局部挫败。

* **反转堆叠**：连续反转令读者脱敏，且多数无铺垫。每卷有效反转2-4次，均需铺垫标注。

* **循环无升级**：网文循环式写作中，对手层级、规则边界、主角认知、代价量级四项全不变的循环是废章。

* **暗线揭示只是补新信息**：不重构读者对已读内容的认知，就不是暗线，只是一段迟到的说明。

* **感情线越位**：感情线推进到支配主线的程度，破坏方向感。感情线按支线纪律管理。

* **悬念链断裂**：兑现后不抛新问题，读者失去翻页理由。任何兑现必须配对一个新抛出。
