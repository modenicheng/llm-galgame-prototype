# 03-人物系统

## 模块定位

本模块管：人物建档体系（五维人物卡、灵魂场、动机内核）、人物分层、人物即过程的档案更新内容、认知滤镜、区分度与标记、主角主动性、反派塑造、群像管理、同人创作中的人物忠实。

本模块不管：人物档案文件如何组织、何时更新（归《09-长篇状态管理》，此处只规定「更新什么内容」）；对话的句法工艺——动作节拍、标签变化、标点规范（归《06-对话工艺》，此处只定义「语言指纹」这一维度及其测试法）；人物一致性「怎么查」（归《10-审计与修订》，此处只写「怎么防」）。

适用阶段：建档于构思后期——立项卡与大纲骨架成形之后、动笔之前；档案更新贯穿全书全程；同人人物的反推在接稿时第一时间完成。

## 一、人物的本质：由约束定义，由选择显影

**目标**：让你建的每一个人物都由「约束」而非「标签」构成，并让人物的真相只在压力下的选择中显影。

**原则**：读者认出一个人物，靠的不是他「是什么」，而是他「不会做什么、必须做什么、怎么说话」。标签是静态描述，约束是可执行的预测器——给你一个新情境，标签回答不了他会怎么做，约束能。

**操作指引**：

1. 建卡前先做删除测试：把「善良、勇敢、忠诚、外冷内热」这类形容词全部删掉，问自己「这个人在 X 情形下会做什么、绝不会做什么」。删完之后卡里还剩下多少可执行内容，就是这张卡的真实价值。
2. 用三层约束替代标签：**不会做什么**（价值底线）、**必须做什么**（行为铁律）、**怎么说话**（语言指纹）。三层分别落到灵魂场与语言指纹两个维度上。
3. 人物真相 = 压力下的选择。闲谈中的人物不构成人物；只有当利益、恐惧、忠诚互相冲突而他选了某一边时，人物才成立。你应当先给他设计一个两难场景（救朋友会暴露自己、说真话会毁掉唯一的机会），再回头填卡——他在两难中的那一次选择，比十页档案更能定义他。
4. 性格靠行为显影，不靠宣告。人物层面的侧面揭示对照表：

| 直接宣告（不要） | 侧面展示（要）     |
| -------- | ----------- |
| 他很愤怒     | 他捏碎了手里的纸杯   |
| 她很紧张     | 她第三次调整眼镜的位置 |
| 他很傲慢     | 他从不直视下属的眼睛  |
| 她很善良     | 她偷偷喂了三年流浪狗  |

泛化的「展示原则」与情绪的感官工艺归《07-文风与反AI味》，此处只约束「性格如何被读者读出」。

1. 首次出场是约束的第一次落地，不是人物介绍。出场方式三选一：行动中（展示能力或性格）、冲突中（立即建立关系与对立）、误解中（建立悬念）。你应当禁止镜子自照式的外貌描写和简历式介绍（姓名＋年龄＋职业＋一句评价）。
   反例：李明，28 岁，是一名侦探。他走进办公室。
   正例：李明跨过警戒线，警官试图拦他。「市刑警队。」他亮出证件，径直走向尸体。
   差别不在信息量，而在第二句里已经有一个正在运行的约束：他不等人，他直奔核心。

**常见误区**：把档案当人物。档案写得越满，正文里人物往往越平——因为满档案通常意味着形容词多、约束少。

## 二、五维人物卡：唯一建档体系

**目标**：用五个固定维度完成所有层级人物的建档，不再引入第二套卡片。

**原则**：五维卡是本书唯一的人物建档体系。声线卡、人物档案、人物矩阵等一切模板的字段都能归入五维；建档成本与戏份的匹配靠分层实现，不靠另立卡片。两套并行的卡必然只有一套被维护，另一套成为错误之源。

### 维度一：基本身份

**目标**：让读者「记住」这个人，而不是「查阅」这个人。

**原则**：身份信息要以记忆锚点的形式存在，不以属性清单的形式存在。

**操作指引**：记录姓名、年龄、性别、职业、时代与背景，外加 **1-2 个记忆锚点**。「左眉一道旧疤、腰上总挂一枚磨亮的铜哨」是锚点；「身高一百八、黑短发、黑风衣」是属性清单。锚点必须能在后文被反复调用（摸疤、吹哨），属性清单不能。姓名可以埋暗示：音韵暗示性格、字义暗合命运、改名或外号暗示人物转变——但只作为暗示埋下，不做明示。

### 维度二：核心性格

**目标**：定义人物的内驱力与应激模式。

**原则**：性格四问全部指向「可预测的行为」，不指向形容词。

**操作指引**：

* **核心驱力**：让他活下去的东西是什么。定主角时先在英雄型（利他、对抗外在威胁）、成长型（从弱小到强大、克服内在缺陷）、反英雄型（道德灰色、挑战传统价值）、平凡型（普通人卷入非凡事、代入感强）四种原型中选一种，它决定核心驱力的写法。

* **价值锚点**：他绝不会做的事——这是灵魂场的原材料。

* **恐惧与执念**：各写一条具体的，不写「怕失去」这种万金油。

* **冲突下的第一反应**：对抗 / 回避 / 观察 / 逃跑，四选一。长篇里同一人物会遇到几十次冲突，第一反应是他的默认档位，偏离默认档位才构成事件。

### 维度三：灵魂场

五维中的关键维度，S/A 层必建，B 层不建。写法与铁律见下一节。

### 维度四：语言指纹

**目标**：让每个开口的人物「遮住名字也能被认出来」。

**原则**：语言指纹是维度定义与测试法，不是句法教程。

**操作指引**：记录五项——

1. **句形**：短句 / 反问 / 自我否定 / 比喻密集，选主导形态；
2. **口头禅**：1-3 个高频标记，超过 3 个等于没有；
3. **禁用词**：这个人物绝不会说的词（一个满口粗话的人不说书面语，一个学者不用网络词——禁用词比常用词更能标记声音）；
4. **愤怒的形态**：冷笑还是爆粗、先动手还是先讥讽、越生气越安静还是越大声；
5. **信息密度**：说三分留七分，还是竹筒倒豆子。

**测试法（遮名测试）**：取一段对话，遮住所有说话人标签与动作节拍中的名字。若仍能从语气判断出每句话是谁说的，通过；若多人的台词可以互换，指纹缺失。句法层面的落实（动作节拍、标签变化、标点规范）参见《06-对话工艺》。

### 维度五：关系网与成长弧

**目标**：让人物有「从哪里来、到哪里去」，且与他人的关系处于可追踪的变化中。

**原则**：成长弧不等于变强。「从希望到清醒」「从复仇到放下」都是合法弧线；只写「越来越强」的弧线是功能升级表，不是人物。

**操作指引**：

1. 成长弧写成「从\_\_\_\_状态到\_\_\_\_状态」，并标注触发转变的关键事件。
2. 关系用有向记录：A→B 与 B→A 分开记，因为两者常常不对称（他视她为救命恩人，她视他为麻烦）。
3. 关系必须有变化轨迹：陌生人→不情愿的盟友→建立信任→背叛或考验→真正的友谊或决裂。停在第一章状态不变的关系是布景。
4. 常用关系类型与戏剧潜力对照：亦敌亦友（高，悬疑动作）、禁忌之爱（高，言情悲剧）、师徒（中，成长故事）、兄弟竞争（中，家庭剧）、陌生人联盟（中，冒险悬疑）——优先选戏剧潜力高的关系承载主线。
5. 关系追踪字段：角色 A / 角色 B / 关系类型 / 信任度（1-10）/ 信息边界 / 最近变化章节。

### 人物分层：S / A / B / C

**目标**：让建档成本与戏份匹配。

**原则**：长篇人物众多，全员满配档案会导致档案系统本身失效——建不动，也守不住。分层是用最小成本守住最大一致性的方法。

| 层级 | 角色            | 建档要求                  | 灵魂场     | 维护成本                             |
| -- | ------------- | --------------------- | ------- | -------------------------------- |
| S  | 主角、核心反派       | 五维全建                  | 5 条（顶格） | 重大选择后更新人物当前状态；不可逆变化时更新档案；每卷末全面回顾 |
| A  | 重要配角、爱人、宿敌、导师 | 五维全建                  | 3-4 条   | 重大选择后更新人物当前状态；不可逆变化时更新档案；每卷末回顾   |
| B  | 常规配角          | 基本身份＋核心性格＋语言指纹＋认知滤镜一行 | 不建      | 出场时顺手更新状态                        |
| C  | 龙套            | 一个记忆钩子＋一句话            | 不建      | 不建档，出场即用即弃                       |

判定规则（升降层链条，与第十节一致）：不确定一个新配角该进哪层时，先按 B 层建；B 层人物在前 10 章内被第二次调用且承担情节功能，升 A 并补齐五维；只出现一次，降 C 并压缩成钩子；C 层人物第二次被需要，升 B 补建。宁可后补，不可预支——预支满配档案的 C 层人物，是长篇档案系统腐烂的第一步。

灵魂场条数上限是 5。超过 5 条会稀释：你自己记不住，读者更记不住，等于没有。

## 三、灵魂场（Soul Field）：3-5 条不可违背的行为铁律

**目标**：给人物一组全书任何情节都不得打破的行为铁律，作为人物一致性的第一道防线。

**原则**：灵魂场是预测器。它存在的意义，是让三十万字之后的你仍能回答「这个人在这种情形下会怎么做」，而不必重读前文。

**写法**：每条铁律必须是可执行句式——「在 X 情形下必做 Y」或「任何情况下不做 Z」。禁止写成价值观：不写「重视忠诚」，写「朋友有难必救且不趁人之危算计」。

示例（一个重情义的武侠主角，5 条顶格）：

* 朋友有难必救，且不趁人之危算计；

* 面对弱者求助不拒；

* 不主动伤及无辜；

* 承诺必兑；

* 被朋友背叛会悲痛，但会给对方一次解释的机会。

注意最后一条：铁律可以规定「以某种特定方式反应」，而不仅仅是「必做」与「不做」——这种反应形态的铁律往往比禁令更能定义人物。

**全书不可违背原则**：一旦设定，任何情节不得打破。读者对人物的信任建立在你三十万字的守约之上；破一次，前面的积累清零。

**剧情与铁律冲突时的两条出路**（没有第三条，不存在「就这一次」）：

1. **改剧情**。优先选项。让情境绕开这条铁律，或者换一个不受此铁律约束的人物去执行这段情节。
2. **改灵魂场**。仅当这次打破本身就是人物的重大转折时使用。此时它不是违规而是事件，必须回改前文：至少 3 处渐进铺垫（对应伏笔三层次中的「重」级），让读者回头看时发现「原来早就松动了」。无铺垫的灵魂场改写就是 OOC。

改灵魂场之后必须回溯检查：已写章节中是否有依赖旧铁律的情节，有则一并修订，否则你会制造一个前后矛盾的人物。

**常见误区**：把灵魂场写成愿望清单（「变得更强」）、写成标签（「讲义气」）、写成超过 5 条的军规。三种都守不住。

## 四、动机内核（Motivation Core）：核心创伤 / 核心欲望 / 核心恐惧 / 核心矛盾

**目标**：给每个人物装上内在引擎，使他的一切重要行为都能回溯到一个可以陈述的原因。

**原则**：灵魂场是外在铁律（他怎么做），动机内核是内在引擎（他为什么这么做）。两者必须能互相推导：从动机内核应能推出灵魂场的每一条；灵魂场的每一条被触碰时，应能感到动机内核的震动。二者只建其一的人物，要么是提线木偶（有铁律无引擎），要么是散沙（有引擎无约束）。

**四件套**：

* **核心创伤**：过去伤害他的事。它决定他习惯性回避什么。

* **核心欲望**：他真正想要的东西——往往不是他嘴上说的那个。

* **核心恐惧**：他最害怕的事。它与核心欲望常是一体两面：欲望是「要」，恐惧是「怕失去」或「怕重演」。

* **核心矛盾**：他内部两股不可调和的力量。温和的人为何会对某件事暴怒、理性的人为何会做出非理性选择——答案都在这里。矛盾越深，人物越立体。

**操作指引**：

1. 四件套每一件都用一句可检验的话写，不用形容词。「核心创伤：十二岁那年被独自锁在阁楼三天」优于「童年不幸」。
2. **回溯链测试**：任何一个重要行为发生后，你需要能答上三个问题——以他的背景，他会有这个反应吗？他的核心恐惧会如何影响这个决定？他的核心矛盾会让他在这里犯什么错？三问有一个答不上来，说明这个行为是你（作者）要他做，不是他自己要做。
3. **缺陷设计**：缺陷是核心矛盾中可执行的那一半。缺陷不能太小（无意义），不能太大（读者会厌恶主角）；最佳缺陷是在特定情境下会变成优点的缺陷。缺陷必须致命化——不在关键时刻造成代价的缺陷只是装饰：傲慢→低估对手落入陷阱；信任问题→拒绝帮助孤立无援；完美主义→无法及时行动错失机会；复仇心→被利用失去理智。
4. **一致性的事前防线**：当你要让人物「不符合性格」行事时，先确认这能从动机内核找到解释，并在同章或下一章给出这个解释。它可以是一次成长的标志（他克服了某个恐惧），但必须是解释过的。具体审计清单与流程参见《10-审计与修订》。

## 五、人物即过程：人物由每次选择重新定义

**目标**：让人物档案成为随正文推进而更新的活文件，而不是写完即弃的设定稿。

**原则**：人物不是建档时定格的静态实体，而是由他做过的每一次重大选择累加定义的。读者对人物的最终印象来自选择序列，不来自第一章的档案。

**操作指引**：

1. **更新触发**：人物每做一次重大选择——改变立场、背叛、承诺、牺牲、拒绝、克服恐惧——你应当当场更新人物当前状态（character-state）；只有当变化不可逆——关系断裂、信念崩塌、能力质变——才更新人物档案并记录变更章节。判断「重大」的标准：这个选择会让熟悉他的人改变对他的预期。
2. **更新字段**（每次触发至少过一遍）：

   * **信念状态**：这次选择验证了还是动摇了他的哪条信念或哪条铁律；

   * **关系变化**：与谁的关系变了什么，信任度 1-10 调整（1-3 敌对/不信任，4-6 中立/合作，7-10 信任/亲密）；

   * **资源增减**：他得到了什么、失去了什么——人手、把柄、名声、身体机能、秘密；

   * **已知信息边界**：他此刻应当知道什么、不知道什么，以及他「知道」的信息里哪些是错的（错误的已知信息是滤镜冲突最好的燃料）；

   * **当前状态**：位置、身体与情绪基线、随身物品；

   * **下一步意图**：他接下来想做什么。
3. **信息边界是长篇防穿帮的第一字段**。「她怎么会知道——她不在那场戏里」这类错误，全部源于信息边界未更新。每章结束前你需要核对：本章揭示的每条信息，加入了哪些人物的边界，又没有加入哪些人的。
4. **每卷末全面回顾**：对 S/A 层人物逐个过一遍四件套与灵魂场，问「这一卷发生的事，有没有让其中任何一条失效或松动」。有，则更新，并检查是否需要回改前文铺垫。
5. **关系网每卷重绘一次**：新增人物入网、死亡或离场人物移除、信任度刷新。关系网是全书最重要的一张「现在时」快照。
6. **状态只进不退**：修订已写章节时，不得让人物状态悄悄退回旧版本而不做记录，否则重写会制造前后矛盾。

档案的文件组织方式、更新时点与分层加载策略参见《09-长篇状态管理》。本模块只规定更新什么内容。

## 六、认知滤镜（Cognitive Bias Pack）：每个人物看世界的角度都不一样

**目标**：给每个人物一副看世界的滤镜，使他眼中的世界与其他人物系统性不同。

**原则**：人物之间的冲突大多是滤镜错位，而非善恶对立。同一个人，主角看是敌人，某个配角看是父亲；同一件事，谁的视点决定读者看到哪一面。没有滤镜的人物只能用同一套通用反应（「心中一震」「眼泪夺眶而出」）发声——这正是人物同质化的根源。

**滤镜三问**（给每个人物各写三行）：

1. **他习惯性误读什么**：把关心读成施舍、把沉默读成轻蔑、把善意读成算计。
2. **他习惯性回避什么**：不碰某类话题、不看某类证据、绕开某类人。
3. **他用什么逻辑解释世界**：先假设最坏再被证据推翻；一切归因于利益；一切归因于宿命；用童年经验映射当下。理性者的内心节拍是步步推进，冲动者的内心节拍是碎片段落——解释逻辑也包含思维的节拍。

**第四行：感官映射**。把抽象情绪绑定到这个人物独有的身体记忆上：他的「孤独」是樟木与灰尘的气味，他的「恐惧」是地板缝隙的凉；另一个人物的「恐惧」是钟表停摆的寂静。同一情绪在不同人物身上呈现为完全不同的意象——这是区分度最省力的来源，因为情绪是全书出现频率最高的东西。感官描写的具体句式工艺参见《07-文风与反AI味》。

**操作指引**：

1. 滤镜在 S/A 层必建；B 层至少写一行解释逻辑；C 层不建。
2. 写冲突时先查双方滤镜：如果这场冲突被你写成了「善与恶」，先尝试改写成「滤镜 A 与滤镜 B 的错位」——后者写出来的人更像人。
3. 视点人物登场时，叙述必须带上他的滤镜：他注意到什么、忽略什么、误会什么。全知式心理归因（「他其实内心深处渴望着……」）是滤镜缺失的表现。
4. 误读、偏见、不可靠叙述是人性感的来源。一个从不误读、从不遗漏、从不带偏见的人物，读起来像作者的传声筒。

## 七、区分度与标记：语言 + 行为双层

**目标**：让读者仅凭行为就能认出舞台上是谁。

**原则**：每个在场人物需要双层可识别标记——语言层＋行为层。只有一层的人物，在同场三人以上时必然混淆。

**标记模板表**（建卡时为每个会开口的人物填一行）：

| 人物 | 语言标记                   | 行为标记         | 他怎么传递信息     |
| -- | ---------------------- | ------------ | ----------- |
| 张磊 | 粗话、自我背书（「我这鼻子二十年没骗过我」） | 嚼草根、吐掉、再嚼    | 靠吹，先声夺人再说   |
| 李薇 | 短句、命令式、绝不解释            | 说话时用手指在地上画图  | 用动作直接演示，不解释 |
| 周野 | 话少，被问急了才开口             | 紧张时反复确认急救包位置 | 不说，用行动交代    |

第四列最容易被忽略也最有价值：**即使是纯信息传递型配角，传递信息的方式也必须是这个人独有的**。情报贩子、引路人、解说者这类功能人物最容易被写成「人形说明书」——他们传递的信息可以是功能性的，但传递方式必须反映性格。

**正例（三人同场，各有标记）**：

> 「老子跟你说，前面那个东西——」张磊把嚼了一半的草根吐在地上，「不对劲。我这鼻子，」他指了指自己的鼻子，「二十年没骗过我。」
> 李薇没搭话。她蹲下来，用食指在泥地上画了个简单的地形图，标了三个点，然后抬头看了他们一眼。意思是：走哪条？
> 周野已经在摸背包侧兜了。他每次紧张的时候都会确认一遍急救包的位置——但嘴上什么都不会说。

三人分别用：语言标记（粗话＋自我背书）、行为标记（画图代替说话、确认急救包）、以及传递信息的方式（一个靠吹、一个靠画、一个干脆不说）。遮住名字也能分辨。

**遮名测试**：成稿后随机抽一章对话较多的场景，遮住名字读一遍。能分辨，通过；不能，为混淆者补标记。

## 八、主角主动性：信息猎手

**目标**：让主角成为信息的主动猎手，而不是被动的接收容器。

**原则**：主角的吸引力来自他对世界施加的力，不来自世界对他的告知。长篇尤其如此——读者要跟着这个人走几十万字，被推着走的人给不了跟随的理由。

**主动性破产的判据**：如果一整章可以压缩成「去了某地→被告知某事→表示震惊」，主动性已经破产。「听完整个解释后只说了一句『这怎么可能』」是最典型的坏信号。你需要在大纲与成稿两个层面都检查这个结构。

**主动行为的合格形态**（三种都算主动）：

1. 主动行为直接揭示新信息：潜入、翻找、实验、跟踪、亲赴现场；
2. 追问迫使对方披露：不是听完，而是问到对方听不完；
3. 被动接收后的立即反制：得到信息后当场做出决策或行动——哪怕是个错误决策。

**操作指引**：

1. 关键信息原则上由主角的主动行为获得。你应当在写大纲时标注每条关键信息的获取方式（主动获取 / 被动接收）；被动接收的关键信息连续出现 3 章以上，判定主动性破产，重排。
2. 每章给主角至少一次「他决定做什么」的时刻——一个不由他人指令、不由环境逼迫、出自他动机内核的决定。决定可以很小（今晚不睡、去查一个人），但必须存在。
3. 被动局面本身不违规。人物被卷入、被欺骗、被打倒是常态；违规的是被动之后没有反应。被骗后反击、被打倒后爬起来、被告知后质疑，都是主动性的形态。
4. 主角的主动性要靠代价平衡：他主动出击，就要承担主动出错的后果。只赢不输的主动是另一种虚假。

## 九、反派塑造：反派是自己故事的主角

**目标**：写出一个拥有完整内在逻辑、撑得起全书对抗的反派。

**原则**：反派不是邪恶的化身，而是另一种价值观的极端代表——他做了和主角相同的逻辑推导，得出了不同的结论。反派失败于立场，不失败于智商。

**操作指引**：

1. **按 S 层建档**：五维全建、灵魂场 5 条、动机内核四件套完整填写。他是自己故事的主角，档案厚度必须与主角对等；档案薄于主角的反派，撑不过三卷。
2. **动机合理化**：扭曲，但要可理解。「我想毁灭世界」乏味；「我失去了一切，世界对我而言已经没有意义」可理解但单薄；「人类是地球的病毒，必须清除」有哲学支撑。四种常用类型：理想主义扭曲（「为了大局必须牺牲」）、过去创伤（「世界这样对我，我就这样对世界」）、权力渴望（「我配得上更多」）、与主角相同目标不同方法。最后一种最耐用，因为它把冲突从善恶改成了路线。
3. **经典三要素**：①与主角有共同的敌人（哪怕双方都不知道）——为后期联手或镜像对照埋下结构可能；②有一个合理的理由相信自己是对的——写不出这条，说明反派只有行为没有立场；③主角身上有他想要但不敢承认的东西——这一条让反派在凝视主角时有了人性的重量。
4. **冲突源于立场错位，不源于智商缺陷**。反派的每次失败应源于其动机内核的固有缺陷——他的核心恐惧让他错过了什么、他的核心矛盾让他在关键处犹豫了多久——而非临场降智。反派一旦开始犯低级错误，全书紧张感即刻清零。
5. **压迫感工程**，反派卡加四项：

   * **压迫感来源**：实力 / 信息差 / 制度 / 道德豁免权，选主用的那一种并贯穿始终；

   * **实力对比曲线**：前期碾压→中期持续施压→后期被翻盘，翻盘点必须落在主角用代价换来的成长上，不能落在反派失误上；

   * **标志性特征**：一个动作或一句口头禅，让他出场三行内被认出；

   * **一个「让读者恨的瞬间」**：一个具体的、针对弱者的、不加辩解的恶行。恨意需要一个具体落点，不能只靠「他很强」。
6. **反派离场后仍有余响**：他塑造过的人物、留下的制度、主角因他改变的观点，都是他的延伸。让反派死得干净，不如让他活得长久。

## 十、群像管理（长篇专项）

**目标**：在数十万字、几十个命名人物中维持群像的存在感与秩序。

**原则**：长篇的群像问题不是「写不好」，而是「记不住＋顾不上」。群像管理是频率与功能的管理，不是塑造深度的管理——深度由五维卡解决，秩序由本节解决。

**操作指引**：

1. **每个命名人物至少一项功能**：推进剧情 / 揭示主角 / 制造冲突 / 象征某种价值观。四选一，不叠加——叠加导致功能模糊。常用配角功能原型可作参考：导师型（指引与传递信息）、盟友型（协助与情感支持）、搞笑型（缓解紧张）、爱情型（制造个人利害）、叛徒型（制造背叛与转折）。一个人物答不上「他存在的理由」，删除或合并。
2. **纯工具人合并删除**：两个功能相同的配角合并成一个——合并后往往更有戏；「只是存在」的角色直接删除。命名人物数量必须控制：每一个命名人物都是一笔未来三十万字的维护负债，不起名是最便宜的控制手段。能用「店小二」「穿灰袍的人」解决的，绝不起名。
3. **出场频率轮换**：重要配角不宜同时扎堆。每一卷安排 A 层人物轮流走到台前，一次集中给一个人戏份，好过所有人平均露面——平均露面的结果是所有人都记不住。
4. **离场过久的存在感维护**：A 层人物离场超过 30-50 章（约一个小弧）时，你需要安排一次低成本的存在感维护——他人在对话中提及、一封来信、一段传闻、一个远景。什么都不做，读者就会在他重新出场时问「这是谁来着」。
5. **关系网每卷重绘**：见第五节。群像的秩序感来自关系网的「现在时」清晰。
6. **C 层不建档**：出场时用一个记忆钩子＋一句话立起来，即用即弃；第二次被需要时升 B 层补建（升降层链条见第二节判定规则）。
7. 多线人物视角的分章与切换纪律参见《05-场景与章节》。

## 十一、同人的人物忠实

**目标**：在同人创作中保住原作人物的行为逻辑，把 OOC 当作最深层的失败模式。

**原则**：同人的任务从「创造」变为「忠实＋延伸」。读者带着对人物的既有认知进场，人物崩坏比情节崩坏致命得多——情节崩坏读者会弃文，人物崩坏读者会觉得被冒犯。情节与人物冲突时，改情节。

**操作指引**：

1. **反推法（接稿第一步）**：采样原作中该人物的代表性对话与动作片段，从中反推出他的灵魂场与语言指纹，落成一张同人专用人物卡。不要凭印象写，要凭采样反推——印象会骗你，原作文本不会。
2. **三区标记**：把人物的行为逻辑划为三区，写作前先判定这场戏落在哪一区：

   * **已确立区**：原作明确展示过的行为与反应。铁律，不得翻转。

   * **有暗示区**：原作留下线索但未明示。可展开，但展开方向必须顺着暗示的纹理。

   * **空白区**：原作未涉及的处境。自由发挥区，同人的生长空间主要在这里。
3. **CP 层级与铺陈成本**：原作官配 > 原作暗示 > 同人共识 > 原创配对。层级越靠外，需要的前置铺陈越多。扭曲人物性格来发糖，读者读到的是背叛而非甜——糖的甜度来自「这就是他会做的事」，不来自「终于在一起了」。
4. **OC 防苏三条**：①给 OC 真实且影响情节的缺陷（「太善良」「太要强」这类伪缺陷不算）；②原作人物不得围绕 OC 运转，他们有自己的动机与日程；③OC 的能力不得越出原作体系上限。违反任何一条，OC 即开始吞噬整个故事。
5. **AU 与 IF**：AU 是把人物移植到新环境，灵魂场与语言指纹必须原样带过去，变的只是处境；IF 线必须在分歧点明确标记，让读者知道从哪一章开始偏离原作。
6. 原作世界观规则的忠实与设定空白区扩展，参见《08-世界观构建》。

## 十二、常见误区

1. **贴标签式塑造**：用「善良、勇敢、忠诚」建档。判据：删掉所有形容词后，卡里还剩什么。修法：全部改写成「在 X 情形下必 Y / 不做 Z」。
2. **无铺垫性格突变**：人物突然变得冷酷、勇敢或堕落，只因剧情需要。判据：这次转变之前有几处铺垫。修法：回改前文加铺垫，或改用另一个人物执行这段情节。
3. **配角围绕主角空转**：配角没有自己的目标，只在主角需要时出现。判据：把这个配角单独拎出来，问他这一卷想要什么——答不上即空转。修法：给他一条与主线有交点但不重合的个人目标。
4. **OOC（同人与原创通用）**：人物做出读者或前文明知他不会做的事。判据：行为能否通过灵魂场与动机内核的回溯链。修法：改情节，不改人物。
5. **档案与正文脱节**：建档后从不更新，第 40 章的行为与第 4 章的设定冲突。判据：上一次更新档案是哪一章。修法：执行第五节的更新纪律。
6. **档案越写越厚**：把建档当成长期工程持续加字段。判据：写正文时你实际查阅的字段有几个。修法：按 S/A/B/C 分层裁剪，删掉没人查的字段。
7. **群像失控**：命名人物越积越多，每个都欠戏。判据：全书命名人物数 ÷ 你能不看档案复述出来的人物数。比值越大于 1 越危险。修法：合并、删除、降层，不起名。
