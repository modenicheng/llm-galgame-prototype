# 08-世界观构建

## 模块定位

本模块管：世界观的规则集本质、三层规则（物理/社会/约束）、六步设计法、冰山原则、展示纪律、常见类型规则模板、规则怪谈专项、设定字典与例外登记、五大陷阱与耦合测试。

不管：题材对文风的取向（归《01-立项与定位》——你管的是「规则体系」，不是「文字气质」）；设定一致性的审计与检测（归《10-审计与修订》——你管的是建档与例外登记的「防」，不管「查」）；设定文件与状态文件的目录组织（归《09-长篇状态管理》——你管的是每个条目该装什么字段）。

调用时机：构思期用六步设计法与三层规则搭骨架、用类型模板起步；初稿期按展示计划向正文投放设定；全书全程维护设定字典与例外登记。

## 一、世界观的本质：规则集，不是百科全书

**目标**：把世界观从「名词堆」改造成一套可执行的规则集——世界能做什么、不能做什么、代价是什么。

**原则**：限制产生冲突的必然性。角色的能力边界与世界的禁区决定了「哪些路走不通」，走不通的路才是情节。规则越明确，冲突越必然；一个什么都可能的世界，什么都不必然发生。

**操作指引**：

* 每条设定必须能回答三个问题：能做什么（许可）、不能做什么（禁区）、代价是什么（成本）。三问缺一，这条设定就是装饰。

* 把设定改写成条件句：「在 X 情形下，Y 成立；违反则 Z」。写不出条件句的设定不是规则，是形容词。

* 判断一条设定是否入册：删掉它，主线冲突是否松脱？松脱→保留；毫无影响→删除，或降级为背景一笔（不给专有名词）。

* 读者读世界观，读的从来不是名词，是名词之间的因果链：灵气→修炼→寿元→争夺，这条链才构成世界。你设计时应先画因果链，再命名节点。

**常见误区**：把力量等级表当世界观。等级表只回答「谁强谁弱」，不回答「为什么非打不可」；没有禁区和代价的设定无法生产情节，只能生产名词。

## 二、三层规则

**目标**：把世界观拆成物理层、社会层、约束层三张规则表，并让三层在全书尺度上依次揭开。

**原则**：三层各司其职——物理层决定世界如何运转，社会层决定冲突以什么制度形式爆发，约束层决定代价与禁区。三层依次揭开对应主角与读者的三次认知升级，也是暗线跨卷积累的骨架（参见《02-大纲架构》三线管理）。

### 2.1 物理层

内容：超自然有无、能量来源、修炼或使用方法、能力边界、代价。

修仙示例：能量＝灵气；方法＝吐纳、结丹、渡劫；边界＝不得违逆天道；代价＝寿元折损、渡劫失败即身死。

你应当最先定死这一层，因为它决定全书所有战斗与升级的天花板。每一项都写成可验证的陈述句，不留「也许」「传说中」——模糊的物理层会在 30 万字后变成你想怎么写就怎么写的后门。

### 2.2 社会层

内容：政治、经济、阶级、法律、文化、禁忌。

社会层不是背景板，是主冲突的承载结构。你要写「个体对抗体制」，就先设计一个具体的压迫性体制：谁征税、谁执法、谁被豁免、反抗者付出什么。

检验问题：把主角的核心冲突放进这个社会结构，冲突是否必然发生？若换成另一个社会结构冲突照样成立，说明社会层没在干活，只是换了套服装的空舞台。

### 2.3 约束层

内容：绝对禁区、代价机制、稀缺资源。

这一层是你与读者之间的契约，必须全书严格执行。稀缺资源决定争夺，绝对禁区决定绝境，代价机制防止力量无限膨胀。约束层一旦松动一次，全书所有规则同时贬值。

世界规则对人物的约束与灵魂场同理：一旦确立，不可为剧情破例，破例要走例外登记（见第八节；参见《03-人物系统》）。

### 2.4 三层依次揭开与全书三次认知升级

长篇不是一次性倒出世界观，而是分三次重构读者的认知：

* **第一卷（物理层揭开）**：读者与主角确认「这个世界能做什么」——核心能力亮相、力量体系首秀、首个代价兑现。

* **中段卷（社会层揭开）**：读者发现「世界为什么是这样」——规则背后谁在得利、谁在承担代价。此处通常抛出暗线，社会层的揭露直接升级主线冲突的量级。

* **末卷（约束层揭开）**：读者发现「这世界真正的代价与禁区」——终极真相重构前两层认知，回收全书大悬念。

检验：如果你的「认知升级」只是敌人换了更大的、数值提高了，重写。认知升级必须改变读者对已读内容的理解，而不是提高数值。

## 三、六步设计法

**目标**：按固定顺序搭骨架，避免边写边补导致规则互相打架。

**原则**：顺序不可颠倒——核心冲突源先于一切细节，每一步都必须服务前一步。

**第一步：核心冲突源。**
操作句式：「这个世界最根本的矛盾是 A 与 B 不可调和。」
检验问题：这个矛盾能否支撑一百万字？主角是否必然被卷入？
写「个体 vs 体制」，先设计压迫性体制；写「人与天争」，先设计天道为何不容人。

**第二步：物理规则。**
操作句式：「能量来源是\_\_；获取方法是\_\_；上限是\_\_；每次使用的代价是\_\_。」
检验问题：上限是否写死？代价是否可感知？

**第三步：社会规则承载主冲突。**
操作句式：「因为物理层的\_\_，社会分化出\_\_阶层；\_\_阶层得利，\_\_阶层承担代价。」
检验问题：主冲突是否由这个结构自然产生，而非靠巧合与反派恶意？

**第四步：约束规则严格执行。**
操作句式：「绝对禁区是\_\_；违反的后果是\_\_；稀缺资源是\_\_，由谁控制。」
检验问题：这条约束是否对主角与反派同样生效？

**第五步：地理与时代。**
操作句式：「故事发生在\_\_时代的\_\_地理格局，这个格局决定了\_\_。」
检验问题：地理是否参与冲突（天堑、资源分布、交通、信息传递速度），还是只是一串地名？

**第六步：生态（3-5 个主种族或物种）。**
操作句式：「主种族是\_\_，其生存逻辑是\_\_，与主角阵营的利害关系是\_\_。」
检验问题：超过 5 个主种族时，砍到 5 个以内。种族数量与读者记忆容量成反比，其余物种按需临时出场即可。

## 四、冰山原则

**目标**：让设定量十倍于展示量，且作者自己必须全知道。

**原则**：读者看到的规则只是水面上的一角，水下的体积撑住这一角的可信度；作者不知道的部分，写出来必然含糊，读者必然察觉。

**操作指引**：

* **十倍原则**：正文每展示 1 条规则，设定字典里应有约 10 条支撑它的规则。展示的是结果，暗藏的是因果。

* **只展示推动当前情节的部分**：这一章用不到的设定，无论多精彩，不写。

* **作者必须知道答案**：谜题的真相、力量体系的天花板、约束层背后的原因，开卷前写进设定字典。连载可以边写边补细节，但三层规则的底层答案不可后补——后补的答案无法与前文已埋的线索严丝合缝。

* 自检问题：「如果读者问'为什么'，我能答到第几层？」答到第二层即合格；连第一层都答不出，这条设定是空心的。

## 五、展示纪律

**目标**：让设定进入正文的方式永远是事件，而不是说明书。

**原则**：读者通过人物的行为、感知与代价习得规则，而不是通过角色互相讲解。设定说明文是长篇读者流失最快的章节类型之一。

**操作指引**：

* **绝不开设定说明书**。判定标准：一段文字删掉后情节照常推进，它就是说明书。「且说这方世界……」式整段讲解，一律禁止。

* **关键规则首次亮相，配一个可感知事件**。让规则当场生效一次：能量体系首次出场，就让主角用一次并当场付出代价；禁忌首次出场，就让一个次要角色违反它并展示后果。

> 正例（规则首亮相配事件）：新规则「燃血术：以自身气血催发三倍战力，事后三日气若游丝」。不写「此界有燃血之法」，而是让主角在追杀中第一次用它脱险，随后三天连筷子都握不住。一次事件同时完成能力展示与代价教学，读者此后自己会替你记着这条规则。

* **用感官锚点落地**：把抽象规则（力量、代价、禁忌）绑定具体生理或物理感受，构造方法参见《07-文风与反AI味》感官锚点部分。

* **规则投放按展示计划分配到章节**：开书前把「读者必须知道的规则清单」排进卷级大纲并标注首次亮相章节。分配建议：

  * 前三章只投放主角生存必需的规则，通常 2-3 条，其余一律延后（参见《11-商业连载》黄金三章）；

  * 每章至多投放 1 条新规则并完成一次事件化展示，同章投放 2 条以上，读者记住率骤降；

  * 每卷投放的规则量与回收的悬念量对齐：小规则挂小悬念，卷级规则挂中悬念，约束层揭示挂大悬念（参见《04-情节与悬念》悬念三级）。

* **让规则通过损失来教学**：展示代价最有效的方式是让主角先吃一次亏。没有吃过亏的代价，读者不会当真。

**常见误区**：用对话讲解规则。两个都知道规则的角色互相复述规则，是最常见的说明书变体——他们不是为了对方而讲，是为了读者而讲。

## 六、常见类型规则模板

模板是起点，不是答案。照抄模板只能保证不出低级错误，不能保证好看；用它起步，然后在「例外」与「代价」两列做出你的差异化。

| 类型    | 能力体系             | 社会结构       | 代价      |
| ----- | ---------------- | ---------- | ------- |
| 仙侠/武侠 | 修炼等级（练气→筑基→金丹……） | 宗门与世家      | 寿元折损    |
| 都市异能  | 能力觉醒             | 现代社会中的隐秘圈子 | 副作用、暴露  |
| 科幻    | 技术能力             | 星际联邦       | 副作用、伦理  |
| 无限流   | 神器空间赋权＋副本奖励      | 副本队伍与主神规则  | 任务失败即死  |
| 克苏鲁   | 知识即力量            | 隐秘学术圈      | 疯狂、人性流失 |

使用规则：

* 先填表，再逐格问「我能否在这一格做出独特组合」。全格照填的世界观，读者三页就认出套路。

* **代价一列不可空缺**。空缺的代价会在 30 万字内必然导致力量体系失控。

* 悬疑、言情、历史等其他类型的规则取向参见《01-立项与定位》。

## 七、规则怪谈专项

规则怪谈是「规则即情节」的类型：世界观设计直接产出可执行的戏剧动作。本节同样适用于任何规则驱动的副本、密室、系统流桥段。

### 7.1 规则真假设计

* 规则分三类：**真规则**（违反即死）、**假规则**（诱导你去违反）、**陷阱规则**（表面自洽，内藏歧义）。

* 一张规则表里多数为真——读者才有遵守的动机；少量为假——读者才有辨析的紧张；陷阱规则每个规则环境至多 1 条，留给关键反转。

* 陷阱的精髓不在「假」，在「歧义」。例：「广播响起后，跟着广播走」——真义是跟着广播的**声音方向**走，而非听从广播的**内容**；声音来自头顶，内容指向楼下，两个方向相反。

* 歧义必须在事后可被读者回溯验证（公平线索）：揭晓时读者能翻回前文找到那句被误读的话。

### 7.2 规则碎片与代价

* 规则碎片（可收集、可消耗的能力单元）必须登记三项：效果、剩余数量、使用代价。

* 消耗型与吸收型不可混用：同一碎片要么用了就没、要么能持续吸收，前后必须一致。中途改读法属于规则让路，是重大缺陷。

* 每次使用付出即时可感知的代价，且代价随使用次数递增——碎片是爽点引擎的燃料，无代价的碎片会烧穿整本书（参见《11-商业连载》爽点引擎）。

### 7.3 三张清单

你必须在世界档案（world.md）中维护三张清单（文件组织归《09-长篇状态管理》，三清单与设定字典、例外登记同驻 world.md）：

* **已确认规则**：规则编号 / 规则内容 / 真假判断 / 验证章节；

* **规则碎片**：碎片名称 / 效果 / 剩余数量 / 使用代价；

* **待验证规则**：规则内容 / 当前假设 / 计划验证章节。

### 7.4 行动前核对与判断过程

* 人物在规则环境行动前，先核对已知规则清单；未核对直接行动属于人物降智。

* **行为与规则矛盾时，必须写出明确的判断过程**：主角为什么敢违反或绕过这条规则。判断依据必须来自已展示的信息，不允许「直觉」「感觉到不对」搪塞。

* 反例：规则说「灯变红时不要移动」，主角抬头看了一眼红灯，然后径直走了出去（无任何判断过程）——这是规则怪谈类最典型的穿帮。

* 违反规则必须有明确理由，且事后有代价兑现。禁止「只有主角能做，其他人不能做」而无解释。

* 其他角色遵守或违反规则的行为必须有合理动机：配角明知故犯地赴死，要写出他的信息差或他想要什么。

## 八、设定字典与例外登记

**目标**：为全书建立唯一事实源，让你在 30 万字后仍能查到「这条规则是第几章定的」。

**原则**：设定一致性的主要敌人不是记忆，是「改了没记」。你的武器是建档与例外登记；检测手段归《10-审计与修订》。

**操作指引**：

* **建档范围**：所有规则、地名、组织、物品、专有名词一律进设定字典。每条包含字段：名称或编号 / 内容（条件句式）/ 所属层（物理、社会、约束）/ 首次确立章节引用 / 当前状态（有效、已废除、部分修改）。

* **既定事实带章节引用**：每条规则标注「第 N 章确立」。一旦入册，正文中打破它必须走例外登记流程，否则按重大缺陷处理。

* **例外登记成立条件**——写例外前必答三问：

  1. 成立条件是什么（何时、何地、何种前提）？
  2. 是否与已确立规则冲突？冲突则先修订旧规则并留修改记录；
  3. 是否会被读者解读为「作者忘了」？会，则需在前文补埋一次可回溯线索。

* **例外登记格式**：例外规则 / 成立条件 / 确立章节 / 影响的旧规则 / 补偿性限制。最后一条不可省——例外必须附带新的限制，防止例外吞并规则。

* **修改记录**：任何对既有设定的调整，保留旧版本与修改原因，不覆盖。

**常见误区**：只记设定不记例外。例外才是穿帮的高发区；而一次例外被无声地用了三次，它就成了新规则——此时必须回头把它扶正为正式规则，否则旧规则形同虚设。

## 九、五大陷阱与耦合测试

逐条判据与修复：

**1. 设定膨胀。**
判据：新增设定前问「是否服务故事」，不服务即删。数量红线：主种族不超过 5 个，主势力不超过卷数的两倍，力量等级带不超过 9 档。另一个信号：设定字典的增速超过正文增速。
修复：合并同类项；把不服务主线的设定降级为背景一笔，收回专有名词。

**2. 设定与情节脱节。**
判据：设定精彩而情节平淡，或情节紧张却用不上设定。
修复：从情节反推设定。列出主线的关键转折点，逐个问「哪条已有设定能在这个转折上发力」；发不了力，就为这个转折定制设定，而不是继续堆设定等情节来用。

**3. 力量体系失控。**
判据：主角能力的增长不再由外部威胁驱动，而是由叙事需要驱动。
修复三件套：**固定天花板**（开卷即写死上限）；**每层代价**（每升一级付出可感知代价）；**升级由外部威胁驱动**（不是「修炼够了」，是「不升就死」）。
量化：力量每提升一档，正文需先铺垫至少一个卷级威胁作为升级动机。

**4. 规则让路。**
判据：规则对主角失效、对敌人生效；或主角面对难题时没用已展示过的某招。
修复：规则对双方一致；主角没用某招，必须在场内给出解释——代价不可承受、条件不满足、或已被敌方针对。「忘了」不是解释。

**5. 文化质感薄。**
判据：世界只有战斗与升级，没有生活。
修复：补衣食住行、问候方式、节庆、禁忌。操作：为主要场景各写 3-5 条日常细节入设定字典，再按冰山原则择 1 条展示。

**耦合测试**：把你的世界观整体搬进另一个完全不同类型的故事，若它依然成立且毫不违和，说明耦合太弱——这个世界观与你的故事没有绑定。强耦合的世界观，抽掉它故事就不成立：抽掉灵气与寿元，修仙只剩武侠；抽掉「知识即疯狂」，克苏鲁只剩怪物打斗。若测试不过，回到六步设计法第一步，把核心冲突源更深地写进物理层。

## 十、高频误区与开卷自检

三条最高频的失误（前文已展开，此处只给快速判据）：

* **开书倾倒设定**：前三章新规则超过 3 条即超标，回到展示纪律重排投放计划。

* **规则随剧情变形**：中途改规则不登记、不解释。任何规则变更必须走例外登记，否则读者记着的旧版本会替你揭穿。

* **力量无代价膨胀**：能力提升没有可感知付出。爽点透支之后无力可爽，每个核心能力必须挂一条递增的代价曲线。

开卷前自检清单：

* [ ] 核心冲突源已写成一句话，且能撑一百万字；

* [ ] 物理层的能量来源、方法、上限、代价四项全部写死；

* [ ] 社会层能自然产出主冲突，而非靠反派恶意；

* [ ] 约束层对主角与反派同样生效；

* [ ] 三层规则的揭开节奏已排进卷级大纲；

* [ ] 力量天花板已定死，且每档升级有外部威胁驱动；

* [ ] 读者必知规则清单已标注首次亮相章节，前三章不超过 3 条；

* [ ] 每条新规则的首亮相都配了可感知事件；

* [ ] 设定字典与例外登记表已建好字段；

* [ ] 耦合测试已跑：抽掉这个世界，故事是否塌方。
